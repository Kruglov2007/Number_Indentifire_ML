# 🧠 MNIST Deep Neural Network from Scratch (NumPy)

Полносвязная глубокая нейросеть (Deep Neural Network) для распознавания рукописных цифр из датасета **MNIST**, написанная **с нуля на чистом NumPy** (без использования готовых фреймворков вроде PyTorch, TensorFlow или Keras).

Этот проект наглядно демонстрирует математику, которая стоит за Deep Learning: матричные вычисления, работу градиентного спуска, алгоритм обратного распространения ошибки (Backpropagation) по цепочке и регуляризацию.

---

## 🛠️ Архитектура и Особенности сети

Модель построена по принципу глубокого обучения (Deep Learning) и имеет следующую структуру слоев:
* **Входной слой:** `784` нейрона (выпрямленные картинки размера 28x28 пикселей, нормализованные в диапазон `0.0 - 1.0`).
* **Скрытый слой №1:** `64` нейрона (функция активации: Сигмоида).
* **Скрытый слой №2:** `32` нейрона (функция активации: Сигмоида).
* **Выходной слой:** `10` нейронов (вероятности классов для цифр от 0 до 9, функция активации: Сигмоида).

### Реализованные фичи:
1. **L2-Регуляризация (Weight Decay):** Штрафует модель за слишком большие значения весов. Это делает веса «гладкими», предотвращает «взрыв градиентов» и помогает бороться с переобучением.
2. **Контроль переобучения (Validation Split):** Датасет разделен на обучающую (50 000 изображений) и валидационную (10 000 изображений) выборки. Точность замеряется на данных, которые сеть никогда не видела в процессе обучения.
3. **Кэширование весов (Weights Caching):** Сеть автоматически сохраняет обученные матрицы весов и смещений в файл `weights_deep.npz`. При повторном запуске скрипт мгновенно загружает их с диска, пропуская этап долгого обучения.

## 📊 Результаты обучения (5 эпох)

Благодаря добавлению второго скрытого слоя и регуляризации модель показывает высокую скорость сходимости и отличную точность:

* **Эпоха №0:** Train Loss: `0.1789` | Validation Accuracy: **94.85%**
* **Эпоха №1:** Train Loss: `0.0775` | Validation Accuracy: **95.52%**
* **Эпоха №2:** Train Loss: `0.0586` | Validation Accuracy: **95.96%**
* **Эпоха №3:** Train Loss: `0.0489` | Validation Accuracy: **96.18%**
* **Эпоха №4:** Train Loss: `0.0424` | Validation Accuracy: **96.34%**

Итоговая точность на независимых валидационных данных составила **96.34%**. Ошибка `Train Loss` снизилась более чем в 4 раза по сравнению со стартом.

## 💻 Инструкция по запуску

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd Number_Indentifire_ML/ML_2
   ```
2. Установите необходимые библиотеки (стандартный стек для Data Science):
   ```bash
   pip install numpy matplotlib
   ```
3. Запустите скрипт:
   ```bash
   python main.py
   ```
   *Примечание: При первом запуске программа автоматически скачает официальный файл датасета `mnist.npz` с серверов Google, сохранит его локально и запустит обучение.*
